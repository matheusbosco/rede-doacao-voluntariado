# Atores e ações — DAI

## Visitante

* Buscar ONGs por nome, cidade ou bairro.
* Buscar campanhas por causa ou tipo de contribuição.
* Consultar o perfil de uma ONG.
* Ver os detalhes e as necessidades de uma campanha.
* Ler as postagens das ONGs.

## Doador/voluntário

* Criar uma conta.
* Entrar na própria conta.
* Declarar uma doação em dinheiro feita fora da plataforma.
* Oferecer itens para uma campanha.
* Oferecer horas de voluntariado.
* Acompanhar a situação das próprias contribuições.
* Editar ou cancelar uma contribuição pendente.

## Responsável pela ONG

* Cadastrar a ONG para análise do administrador.
* Atualizar o perfil e os dados da ONG.
* Criar e editar campanhas.
* Publicar, pausar ou encerrar campanhas.
* Publicar, editar e excluir postagens.
* Analisar contribuições e aceitar ou recusar ofertas.
* Confirmar o recebimento das doações ou a realização do voluntariado.
* Consultar, filtrar e exportar o relatório das contribuições.

## Administrador

* Listar os cadastros de ONGs que aguardam aprovação.
* Consultar os dados enviados pela ONG.
* Aprovar o cadastro de uma ONG.
* Recusar o cadastro de uma ONG, informando o motivo.
